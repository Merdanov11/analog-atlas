# Use of Super Intelligence (SI / AI) tools

*DRAFT written by the assistant from what it could observe. The team must read it, correct anything that is not accurate, and add anything it could not see (for example work done before this repository was handed to the assistant).*

**Tool used:** Claude Code (Anthropic, model Claude Sonnet 5.5), an AI coding assistant, running on a team member's computer.

**What the team did:** defined the concept (a route navigator for the Moon and Mars on NASA data, with a driving simulator, an astronaut that can leave the rover, a drone, a shared multi-player world, live data from real NASA rovers and mobile support), chose the features and priorities, tested the result and decided what to keep.

**What the SI tool did:**

* **Code:** wrote and edited most of the source code of the driving simulator (`web/sim/*`), the multiplayer server (`server/multiplayer.py`), the live NASA data module (`server/assets.py`), the terrain patch generator (`server/terrain.py`), the drone and walker models, the map interface changes (layers, live vehicles, route de-duplication, mobile layout) and the tests in `tests/`.
* **Documentation and presentation:** wrote the README, the submission texts, the 7-slide demo deck (`docs/demo/`) and the long presentation (`web/presentation.html`).
* **Tooling:** wrote the screenshot harness (`tools/shots.py`) that produced the images in `web/img/`.
* **Research:** looked up NASA data sources (MMGIS, Solar System Treks layer catalogue) and the challenge rules.

**Images and video:** none of the images in this project were generated by an image or video model. All pictures in `web/img/` are screenshots of the running application (terrain and 3D models are rendered by our own code from NASA elevation data). Planet textures in the presentation are NASA Solar System Treks tiles.

**Audio:** the ambient sound in the presentation is synthesised in the browser by our own code (Web Audio API); no recorded or AI-generated music is used.

**Data:** no data was generated by SI. The simulator's small craters and rocks are produced by a deterministic algorithm written by the SI assistant and are labelled as a statistical model, not as measurements.

**NASA branding:** no NASA logos, flags or mission identifiers are used or generated.

Every source file written or modified with the assistant carries a header comment naming the tool.
