# Use of Super Intelligence (SI / AI) tools

*DRAFT written by the assistant itself from what it can observe. The team must read it, correct anything that is not accurate, and make sure the SI answer on the project form says the same.*

**Tool:** Claude Code (Anthropic, model Claude Sonnet 5.5), an AI coding assistant, running on a team member's computer during the hackathon.

**What the team did:** chose the challenge ("Identify Earth Locations that Analog the Permanent Moon Base Locations and Mars"), set the goal (a tool that searches the whole Earth and explains analogies), reviewed the intermediate results, and decided what to publish.

**What the SI tool did, including the idea:** the assistant proposed and implemented the *method*: comparing Earth with Moon and Mars on one common spatial scale (48 km windows with 480 m cells), splitting "analogous" into three separately weighted dimensions (terrain, environment, ice/wind/volcanism), clipping Moon and Mars climate values to what exists on Earth, labelling places as "well-known" or "less-studied", and showing where each analogy breaks down. The rules say SI should not be used to come up with the idea of how to solve the challenge; this project does not meet that expectation in full, and we say so openly.

**Code:** the assistant wrote the data pipeline (`analogs/`), the scoring (`analogs/score.py` and its JavaScript twin in `docs/atlas/index.html`), the web tool (`docs/atlas/`), the tests (`tests/atlas_parity.py`), the screenshot and PDF tools (`tools/`), the README, the form texts and the demo deck (`docs/`). Source files carry a header comment naming the tool.

**Data:** no data was generated by SI. All numbers come from NASA and other open datasets listed in the README; the Moon and Mars climate values and the list of well-known analog sites are rounded literature-based values typed by the assistant and must be reviewed by the team.

**Images, video and audio:** none were generated by an image, video or audio model. All pictures are screenshots of the running application (maps use NASA GIBS imagery; hillshades are rendered by our own code from elevation data). No NASA logos or mission identifiers are used.
